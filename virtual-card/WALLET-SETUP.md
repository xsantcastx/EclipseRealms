# Add the cards to Apple Wallet & Google Wallet (free)

Apple and Google only accept a **signed Wallet pass** — a website or a saved contact
can't become one. The fastest free way to get a real "Add to Apple Wallet" /
"Add to Google Wallet" button is a free digital-card app that does the signing for you.

**Recommended app: HiHello** (free) — has both wallet buttons built in.
Works on iPhone and Android. (Blinq is a good alternative and works the same way.)

You'll make **one card for Angela** and **one card for Carlos**. All their info is below,
ready to copy.

---

## Steps (do this once per person)

1. **Install HiHello** from the App Store / Google Play (or open **app.hihello.com**). Sign up free.
2. Tap **＋ → Create a card** (choose a "Personal" or "Business" card).
3. **Fill in the fields** using the info blocks below.
4. **Add branding:**
   - Company logo → upload the **lotus logo** (`logo.jpg` in this folder).
   - Profile photo → upload a photo of the person.
   - Accent color → pick **magenta / pink** to match the brand.
5. **Add to Wallet:** open the finished card → **Share** (or the card's menu) →
   - On **iPhone**: tap **Add to Apple Wallet** → **Add**.
   - On **Android**: tap **Add to Google Wallet** → **Save**.
   The card is now in the phone's Wallet. ✅
6. **Share with colleagues:** HiHello gives a **link + QR code**. When colleagues open it and
   tap **Save**, they can add *their own* copy to *their* Wallet too.

> 💡 Tip: set the card's **Website** field to our branded card link (below) so the Wallet
> pass points back to the nice lotus page. Once GitHub Pages is on, those links are:
> - Angela: `https://xsantcastx.github.io/EclipseRealms/virtual-card/`
> - Carlos: `https://xsantcastx.github.io/EclipseRealms/virtual-card/carlos/`

## If you'd rather own it fully (no third-party app)

A self-owned pass can be built directly into these cards, but it requires paid/registered
signing credentials:

- **Apple Wallet** — Apple Developer Program ($99/yr) + a Pass Type ID certificate.
- **Google Wallet** — a free Google Wallet API **Issuer** account + a service-account key.

If you get those, the "Add to Apple Wallet" / "Add to Google Wallet" buttons can be generated
and wired straight into `index.html` / `carlos/index.html`. Ask and it can be scaffolded.
